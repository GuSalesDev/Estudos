Um **algoritmo** é um **conjunto finito de passos lógicos e bem definidos** usados para resolver um problema ou executar uma tarefa.

### Explicando de forma simples:

É como uma **receita de bolo**:

- Tem início
- Tem etapas organizadas
- Tem um objetivo final

### Características de um algoritmo:

- **Finito** → sempre termina
- **Ordenado** → segue uma sequência lógica
- **Sem ambiguidades** → cada passo deve ser claro
- **Tem entrada e saída** → recebe dados e produz um resultado

### Exemplo simples (somar dois números):

1. Receber o número A
2. Receber o número B
3. Somar A + B
4. Mostrar o resultado

### Exemplo do dia a dia:

**Fazer café:**

1. Ferver água
2. Colocar café no filtro
3. Despejar água
4. Servir
