
## POWER QUERY

Ferramenta de ETL do Excel para importar, transformar e limpar dados de várias fontes.

> [!info]
> Sintaxe / Fórmula
> 
> `Dados > Obter Dados (Power Query)`

Exemplo prático

> [!example]
> Importar CSV, remover colunas desnecessárias e mesclar com outra tabela, tudo sem fórmulas

## POWER PIVOT

Modelo de dados interno do Excel para relacionar tabelas e criar métricas com DAX.

> [!info]
> Sintaxe / Fórmula
> 
> `Guia Power Pivot > Gerenciar`

Exemplo prático

> [!example]
> Relacionar tabela de Vendas com tabela de Produtos pelo ID e criar medidas DAX

## MACROS

Gravação automática de ações repetitivas para serem reproduzidas com um clique.

> [!info]
> Sintaxe / Fórmula
> 
> `Exibir > Macros > Gravar Macro`

Exemplo prático

> [!example]
> Gravar a macro de formatar relatório (negrito, cor, bordas) e reutilizar

## VBA

Linguagem de programação do Excel para automatizar tarefas complexas.

> [!info]
> Sintaxe / Fórmula
> 
> `Alt+F11 para abrir o editor VBA`

Exemplo prático

> [!example]
> Sub EnviarEmail() → código que envia e-mail automaticamente a partir de uma planilha

## DASHBOARDS

Painel visual interativo com gráficos, indicadores e segmentações para análise de dados.

> [!info]
> Sintaxe / Fórmula
> 
> `Combinação de: Tabela Dinâmica + Gráfico + Segmentação`

Exemplo prático

> [!example]
> Dashboard de vendas com KPIs, evolução mensal e filtros por região

## PROTEÇÃO DE PLANILHAS

Impede alterações em células, fórmulas ou estrutura da planilha.

> [!info]
> Sintaxe / Fórmula
> 
> `Revisão > Proteger Planilha`

Exemplo prático

> [!example]
> Bloquear fórmulas mas deixar apenas células amarelas editáveis para o usuário

## SOLVER

Ferramenta de otimização para encontrar o melhor valor possível com restrições.

> [!info]
> Sintaxe / Fórmula
> 
> `Dados > Solver (ativar em Suplementos)`
> 

Exemplo prático

> [!example]
> Maximizar lucro ajustando quantidades produzidas, respeitando capacidade de estoque

## CENÁRIOS

Salva diferentes conjuntos de valores para comparar resultados (melhor caso / pior caso).

> [!info]
> Sintaxe / Fórmula
> 
> `Dados > Análise de Hipóteses > Gerenciador de Cenários`

Exemplo prático

> [!example]
> Criar cenário 'Otimista' (vendas +20%) e 'Pessimista' (vendas -15%)

## ANÁLISE DE HIPÓTESES

Conjunto de ferramentas: Atingir Meta, Tabela de Dados e Cenários.

> [!info]
> Sintaxe / Fórmula
> 
> `Dados > Análise de Hipóteses`

Exemplo prático

> [!example]
> Atingir Meta: quanto preciso vender para lucrar R$ 50.000?

## IMPORTAÇÃO DE DADOS

Conecta o Excel a fontes externas: CSV, banco de dados, web, APIs.

> [!info]
> Sintaxe / Fórmula
> 
> `Dados > Obter Dados`

Exemplo prático

> [!example]
> Importar dados de uma API web ou banco SQL Server diretamente no Excel

## CONSOLIDAÇÃO DE DADOS

Une dados de múltiplas planilhas ou pastas de trabalho em uma única tabela.

> [!info]
> Sintaxe / Fórmula
> 
> `Dados > Consolidar`

Exemplo prático

> [!example]
> Consolidar vendas de janeiro, fevereiro e março em uma única aba de resumo

## ATALHOS DE TECLADO

Combinações de teclas para acelerar o trabalho no Excel.

> [!info]
> Sintaxe / Fórmula
> 
> `Vários atalhos`

Exemplo prático

> [!example]
> Ctrl+Shift+L = Filtro | Ctrl+T = Tabela | Alt+= = AutoSoma | F4 = Travar referência
