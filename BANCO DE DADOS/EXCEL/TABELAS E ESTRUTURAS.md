
## TABELAS ESTRUTURADAS

com referências automáticas e filtros.

> [!info]
> Sintaxe / Fórmula
> 
> `Ctrl+T ou Inserir > Tabela`

Exemplo prático

> [!example]
> =SOMA(Tabela1[Vendas]) → referência automática à coluna Vendas da tabela

## TABELA DINÂMICA

Resume e analisa grandes volumes de dados de forma interativa, sem fórmulas.

> [!info]
> Sintaxe / Fórmula
> 
> `Inserir > Tabela Dinâmica`

Exemplo prático

> [!example]
> Arraste 'Região' para Linhas e 'Vendas' para Valores → soma por região automaticamente

## GRÁFICOS

Visualização gráfica de dados. Suporta barras, linhas, pizza, dispersão, etc.

> [!info]
> Sintaxe / Fórmula
> 
> `Selecione dados > Inserir > Gráfico`

Exemplo prático

> [!example]
> Selecione A1:B12 e insira um gráfico de linhas para ver evolução mensal

## FORMATAÇÃO CONDICIONAL

Aplica formatação visual (cores, ícones) automaticamente baseada em regras.

> [!info]
> Sintaxe / Fórmula
> 
> `Página Inicial > Formatação Condicional`

Exemplo prático

> [!example]
> Células com valor > 1000 ficam verdes, < 500 ficam vermelhas

## VALIDAÇÃO DE DADOS

Limita o tipo de dado que pode ser inserido em uma célula (lista, número, data).

> [!info]
> Sintaxe / Fórmula
> 
> `Dados > Validação de Dados`

Exemplo prático

> [!example]
> Criar lista suspensa com: SP, RJ, MG, RS para a coluna de estados

## FILTROS

Permite filtrar linhas de uma tabela com base em critérios visuais.

> [!info]
> Sintaxe / Fórmula
> 
> `Dados > Filtro ou Ctrl+Shift+L`

Exemplo prático

> [!example]
> Filtrar apenas vendas da região 'Sul' acima de R$ 5.000

## CLASSIFICAÇÃO DE DADOS

Ordena os dados de uma planilha por uma ou mais colunas.

> [!info]
> Sintaxe / Fórmula
> 
> `Dados > Classificar`
> 

Exemplo prático

> [!example]
> Ordenar clientes por nome (A-Z) e depois por valor (maior para menor)

## SEGMENTAÇÃO DE DADOS

Botões visuais e interativos para filtrar Tabelas Dinâmicas com um clique.

> [!info]
> Sintaxe / Fórmula
> 
> `Análise de Tabela Dinâmica > Inserir Segmentação`

Exemplo prático

> [!example]
> Clique em 'Janeiro' na segmentação para ver só os dados desse mês
