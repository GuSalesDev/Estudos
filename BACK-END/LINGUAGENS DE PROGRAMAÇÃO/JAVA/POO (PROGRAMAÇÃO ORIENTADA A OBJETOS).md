
## CONCEITO

Java é **100% orientado a objetos** (exceto tipos primitivos).  
Os **4 pilares da POO** são fundamentais.

#### ORIENTAÇÃO A OBJETOS

Em Orientação a objetos temos que entender alguns conceitos importantes como:

- objeto:
  Um objeto pode ser qualquer coisa que exista, por exemplo uma pesssoa, um controle, um computador, um carro ou qualquer outra coisa, as possibilidades são infinitas.

- Atributos:
  Atributos são as características de um objeto, como uma pessoa, ela tem altura, nome, idade, peso, cpf e muitas outras coisas.
  Um fator importante para definir os atributos de um objeto é a abstração, você não precisa pegar todos os atributos de um objeto da vida real mas somente aqueles que fazem sentido para o sistema que você está construindo.

-  Métodos: 
   Métodos são comportamentos que um objeto pode ter, por exemplo um cachorro pode latir, comer, dormir.
   Método é aquilo que o objeto faz.
